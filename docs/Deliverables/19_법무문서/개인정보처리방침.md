# VEDA 개인정보 처리방침 (초안)

> **초안 — 변호사 검토 전에는 공개하지 않는다.** 2026-10-14 개발PM 지시(D-09 재결정)로 작성했다. 작업 T-147.
> `[확인 필요]` 표시는 회사 정보이거나 운영에서 값을 정해야 하는 칸이다. 공개할 때 채우고 시행일을 적는다.
> 작성 기준: 개인정보 보호법(2026. 9. 11. 시행)과 시행령, 개인정보보호위원회 「개인정보 처리방침 작성지침」(2026. 4. 개정).

[확인 필요: 회사 상호](이하 "회사")는 사내 규정 관리 서비스 VEDA(이하 "서비스")를 운영하면서 개인정보 보호법을 지키고, 정보주체의 개인정보를 보호하고 관련 고충을 원활하게 처리하기 위해 이 처리방침을 둡니다.

## 1. 회사의 두 가지 지위

서비스는 기업 고객(이하 "고객사")이 계약하고 고객사 임직원이 쓰는 기업용 서비스입니다. 그래서 회사가 다루는 개인정보는 두 가지로 나뉩니다.

| 구분 | 누구의 정보 | 회사의 지위 |
|---|---|---|
| 회사가 직접 처리하는 정보 | 고객사 계약 담당자·관리자의 연락처, 서비스 보안·운영 기록 | 개인정보처리자 |
| 고객사를 위해 처리하는 정보 | 고객사 임직원 계정, 고객사가 서비스에 입력한 규정 본문·의견·질문 | 수탁자 (고객사가 개인정보처리자) |

고객사를 위해 처리하는 정보는 고객사와 맺은 개인정보 처리위탁 계약서에서 정한 목적과 범위 안에서만 처리합니다. 고객사 임직원은 개인정보 열람·정정·삭제를 소속 고객사에 요청할 수 있고, 회사는 고객사의 요청에 따라 돕습니다.

## 2. 처리하는 개인정보의 항목과 목적

| 항목 | 목적 | 수집 방법 |
|---|---|---|
| 이름, 이메일, 비밀번호(복원할 수 없게 해시해서 저장), 역할(관리자·편집자·열람자), 소속 고객사 | 계정 발급, 로그인, 권한 관리 | 회사나 고객사 관리자가 계정을 만들 때 |
| 로그인 기록: 기기별 세션, 마지막 사용 시각, 브라우저 정보(User-Agent) | 로그인 유지, 다른 기기 로그아웃, 부정 사용 방지 | 로그인할 때 자동 생성 |
| 서비스 이용 기록: 규정 편집·승인·폐지 같은 작업 기록(감사 로그), 의견, 즐겨찾기, 알림 | 개정 이력 관리, 감사, 협업 | 서비스를 쓸 때 자동 생성·입력 |
| 고객사가 입력한 규정 본문·별표·첨부 파일에 들어 있는 개인정보(예: 위원회 구성원·담당자 이름) | 규정 편집·열람·출력 | 고객사가 입력 |
| 규정 질문 내용과 AI 답변, 근거 조문, 사용량 | 규정 질문 기능 제공, 회사별·직원별 월 사용 한도 관리 | 고객사가 규정 질문을 켠 경우, 임직원이 질문할 때 |
| 접속 IP, 접속 일시(웹 서버 로그) | 장애 대응, 보안 사고 조사 | 접속할 때 자동 생성 |

- 규정 질문에는 건강·가족 일 같은 민감한 내용을 적지 말라고 화면에서 안내합니다. 회사는 민감정보를 따로 수집하지 않습니다.
- 서비스는 로그인을 유지하려고 브라우저 저장소(localStorage)와 쿠키를 씁니다. 광고·행동 분석용 쿠키는 쓰지 않습니다.

## 4. 개인정보 처리의 위탁

회사는 서비스 제공을 위해 아래와 같이 개인정보 처리 업무를 맡깁니다. 고객사를 위해 처리하는 정보를 다시 맡기는 것(재위탁)은 고객사와의 개인정보 처리위탁 계약서로 미리 동의를 받습니다.

| 수탁자 | 맡기는 업무 | 위치 |
|---|---|---|
| [확인 필요: Oracle Cloud Infrastructure 계약 법인명] | 서버·데이터베이스·파일·백업 저장소 운영 | 대한민국(춘천·서울 리전) |
| Anthropic, PBC | 규정 질문 답변 생성(고객사가 기능을 켠 경우에만) | 미국 — 아래 5항 국외 이전 |

수탁자를 바꾸거나 새로 둘 때는 이 처리방침으로 알리고, 고객사에는 계약서에서 정한 대로 미리 알립니다.

## 5. 개인정보의 국외 이전

회사는 규정 질문 기능에서 답을 쓰려고 아래와 같이 개인정보를 국외로 처리위탁합니다.

- **법적 근거**: 「개인정보 보호법」 제28조의8 제1항 제3호(정보주체와의 계약 체결·이행을 위한 국외 처리위탁으로서 처리방침에 공개). 고객사를 위해 처리하는 정보는 고객사와의 개인정보 처리위탁 계약서로 재위탁·국외 이전에 대한 고객사 동의를 받습니다.

| 구분 | 내용 |
|---|---|
| 이전받는 자 | Anthropic, PBC (개인정보 문의: privacy@anthropic.com) |
| 이전 국가 | 미국 — 답변 생성(추론)을 미국에서만 하도록 지정해 요청합니다 |
| 이전 시기와 방법 | 고객사 관리자가 규정 질문을 켠 뒤, 임직원이 질문할 때마다 암호화된 통신(TLS)으로 전송 |
| 이전 항목 | ① 질문 내용(질문에 적힌 개인정보 포함) ② 회사 규정의 조 목차(규정 이름·조 번호·조 제목) ③ 질문과 관련된 조문의 본문(조문에 들어 있는 개인정보 포함). 이름·이메일 같은 계정 정보는 보내지 않습니다 |
| 이용 목적 | 질문에 대한 답변 생성. Anthropic 은 계약상 이 정보를 인공지능 모델 학습에 쓰지 않습니다 |
| 보유·이용 기간 | Anthropic 정책상 받은 날부터 30일 안에 삭제. 다만 이용정책 위반으로 판정된 내용은 최대 2년, 법령에 따라 보관해야 하는 내용은 그 기간 동안 보관될 수 있습니다 |
| 거부 방법과 효과 | 규정 질문은 처음에 꺼져 있고, 고객사 관리자가 고지를 확인해야 켜집니다. 관리자는 언제든 [규정 질문] 화면에서 끌 수 있고, 끄면 외부로 보내지 않습니다. 끄더라도 규정 질문 말고 다른 기능은 그대로 쓸 수 있습니다 |

## 6. 개인정보의 제3자 제공

회사는 개인정보를 제3자에게 제공하지 않습니다. 법령에 특별한 규정이 있는 경우는 예외입니다.

## 7. 정보주체의 권리와 행사 방법

- 정보주체는 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다.
- 고객사 임직원의 정보는 고객사가 개인정보처리자이므로 소속 고객사 관리자에게 먼저 요청해 주세요. 회사로 요청하면 고객사에 전달하고 처리를 돕습니다.
- 회사가 직접 처리하는 정보는 아래 개인정보 보호책임자에게 이메일로 요청할 수 있고, 회사는 지체 없이 조치합니다.

## 8. 안전성 확보 조치

- 비밀번호는 복원할 수 없는 방식(bcrypt)으로 해시해 저장합니다. 로그인 갱신 토큰도 원문 대신 해시만 저장합니다.
- 서비스와 브라우저 사이, 서비스와 Anthropic 사이의 통신은 암호화(HTTPS·TLS)합니다.
- 서버 디스크와 백업 저장소는 클라우드 기본 설정으로 암호화(AES-256)됩니다.
- 고객사별로 데이터를 나누어 다른 고객사가 볼 수 없게 하고, 역할에 따라 접근 권한을 둡니다.
- 규정 편집·승인·설정 변경 같은 중요한 작업은 감사 로그로 남깁니다.
