
`/tmp/recon.log` 출력을 확인한다. 특히 아래 3가지가 이후 절차를 좌우한다.

1. **6번 항목 "기본값 잔존 항목 수"** — 0이 아니면 5단계(시크릿) 필수
2. **7번 항목 `sections` 존재 여부** — `f`면 6단계(드리프트) 필수
3. **7번 항목 실데이터 규모** — 백업 크기 가늠

## 5. 위험 요소 (반드시 읽을 것)

### 위험 1 — 시크릿 가드로 API가 뜨지 않음
이번 배포에 **기본 시크릿 차단 기능**이 포함된다. `NODE_ENV=production`에서 아래가 남아 있으면 **API가 기동을 거부**한다.

- `JWT_SECRET` / `JWT_REFRESH_SECRET`이 리포에 적힌 기본값이거나 32자 미만이거나 서로 같은 경우
- `MINIO_SECRET_KEY`가 `minioadmin123`
- `DATABASE_URL`이 `postgres:postgres`

→ **웹만 새로 뜨고 API가 죽는 상황**이 생길 수 있다. 조사 6번이 0이 아니면 배포 전에 5단계를 끝낸다.

### 위험 2 — 스키마 드리프트 (가장 위험)
6월 DB에는 `sections` 테이블(절, 8-02 도입)이 **없다.** 그런데 baseline 마이그레이션 안에는 있다.
기동 스크립트의 자동 baseline 처리는 baseline을 **실행하지 않고 "적용됨"으로 표시**하므로,
그대로 두면 **테이블이 없는 채 적용 완료로 기록**되어 런타임에 깨진다.

→ 자동 처리에 맡기지 말고 6단계에서 실제 차이를 뽑아 검토 후 적용한다.

## 6. 절차

```bash
# ── 1) 백업 (필수, 건너뛰지 말 것)
docker compose exec -T postgres pg_dump -U "${POSTGRES_USER:-postgres}" "${POSTGRES_DB:-policy_manager}" \
  > ~/backup_$(date +%F_%H%M).sql
ls -lh ~/backup_*.sql          # 0바이트가 아닌지 반드시 확인

# ── 2) 소스 갱신
git fetch origin
git checkout develop && git pull origin develop
git log -1 --oneline           # 59ac8e1 이상인지 확인

# ── 3) 시크릿 정리  (조사 6번이 0이면 건너뜀)
#     openssl rand -base64 48  로 값을 만들어 .env에 기입
#     주의: DB·MinIO 시크릿은 볼륨에 굳어 있다. POSTGRES_PASSWORD를 바꾸려면
#           먼저 DB 안에서 ALTER USER 로 바꾸고 .env를 맞춘다(볼륨 삭제 금지).
docker compose config | grep -cE 'your-super-secret|minioadmin123|postgres:postgres@'
#     → 0이 될 때까지 반복

# ── 4) 스키마 드리프트 확인 (적용 아님, SQL만 생성)
docker compose exec -T api npx prisma migrate diff \
  --from-url "$DATABASE_URL" \
  --to-schema-datamodel prisma/schema.prisma \
  --script > /tmp/drift.sql
cat /tmp/drift.sql
#     DROP TABLE / DROP COLUMN 이 보이면 적용하지 말고 개발팀에 문의.
#     CREATE TABLE "sections" 등 추가 DDL만 있으면 정상이다.

# ── 5) 재배포
docker compose up -d --build
docker compose logs -f api
#     'migrate deploy completed.' 와 'Application is running on port' 확인
#     시크릿 관련 에러로 멈추면 3)으로 돌아간다
```

## 10. 별건 — 보안 조치 권장 (배포와 별개)

1. **`/api/docs`(Swagger)가 인증 없이 공개**돼 있다. 운영에서는 차단하거나 인증 뒤로 옮긴다.
2. **평문 HTTP**로 서비스 중이다. 로그인 토큰이 그대로 오간다. HTTPS 적용 권장.
3. 기본 시크릿을 쓰고 있었다면, 그 값은 리포에 공개돼 있으므로 **이미 노출된 것으로 간주**하고 교체 후 세션을 만료시킨다.
