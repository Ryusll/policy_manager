## 발견 사항

### 1. docker-compose.yml 기본 시크릿 하드코딩
운영 배포 시 반드시 교체해야 하는 값이 예시 문자열 그대로 커밋되어 있음.

| 위치 | 값 | 비고 |
|------|-----|------|
| `docker-compose.yml:7` | `POSTGRES_PASSWORD: postgres` | DB 비밀번호 기본값 |
| `docker-compose.yml:37` | `MINIO_ROOT_PASSWORD: minioadmin123` | 객체 스토리지 관리자 비밀번호 |
| `docker-compose.yml:54` | `JWT_SECRET: your-super-secret-jwt-key-change-in-production` | 액세스 토큰 서명 키 |
| `docker-compose.yml:55` | `JWT_REFRESH_SECRET: your-super-secret-refresh-key-change-in-production` | 리프레시 토큰 서명 키 |
| `docker-compose.yml:67` | `MINIO_SECRET_KEY: minioadmin123` | 객체 스토리지 액세스 시크릿 |

- 위험: 이 값들을 override 없이 그대로 운영에 올리면 DB·스토리지·JWT 서명이 공개된 기본값으로 노출됨
- 권장: 운영 배포 전 `.env` 또는 별도 secret 관리로 전체 override, 로컬/개발용 기본값과 운영용을 명확히 분리
