## 1. 기능 작업 (무엇을 만들었는가)

### 1.1 회사별 규정 템플릿

| 기능 | 설명 |
|------|------|
| 템플릿 CRUD | 테넌트 단위로 템플릿 생성·조회·수정·삭제 |
| 기본 템플릿 | 테넌트당 기본 템플릿 1개 지정 (`set-default`) |
| 템플릿 복제 | 기존 템플릿을 이름 변경하여 복제 |
| 규정 연결 | `Policy.templateId`로 규정별 적용 양식 선택 |
| 전문 렌더 통합 | 규정 상세 **전문 보기**·**전체화면 전문**·**인쇄**에 동일 템플릿 렌더 적용 |

### 1.2 플랜별 정책

| 플랜 | 템플릿 |
|------|--------|
| Starter | 템플릿 API 미사용(플랜 가드), 규정에 `templateId` 연결 불가, UI에서 업그레이드 유도 |
| Pro | 템플릿 생성·적용·**기본 빌더**(`mode: basic`, `basicConfig`) |
| Enterprise | Pro 기능 + **HTML/CSS 자유 편집**(`mode: html`, `rawHtml` + `cssText`) |

### 1.3 Pro 기본 템플릿 빌더 (`basicConfig`)

- 상단 제목 / 코드·메타 / 기준일 / 조문 제목 표시 여부  
- 푸터 문구  
- 로고(브랜드 스토어) 표시·최대 높이  
- 결재 라인·라벨  
- 인쇄: A4 여백, 장 단위 페이지 나눔, 페이지 번호  

### 1.4 설정 화면 (`양식 관리` 탭)

- 템플릿 목록·선택·저장·기본 지정·복제·삭제  
- **실시간 미리보기** (현재 편집 내용 반영)  
- **미리보기 대상 규정** 선택 (실제 `GET /policies/:id` 데이터)  
- JSON **보내기** (`schemaVersion`, `exportedAt` 포함)  
- JSON **가져오기** (스키마 검증 + 이름 충돌 시 `(2)` 접미사)  
- **이력 조회** (`GET /templates/:id/revisions`)  
  - 검색·액션 필터·기간·정렬·더보기(+10)  
  - 영향도 배지(critical/normal/minor), 변경 필드 수, layout/css 세부 배지  
  - Before/After 라인 하이라이트, Semantic diff, 변경 필드만 보기  
  - **복원 전 확인 모달** 후 `PUT`으로 복원  

### 1.5 규정 상세 (`PolicyDetailPage`)

- 적용 양식 `<select>` (Pro 이상)  
- Starter 시 셀렉트 비활성 + **플랜 보기** → `PlanModal`  
- 전체화면 전문 모달: `Esc` 닫기, 인쇄  

### 1.6 요금제 비교 UI

- `PlanModal`에 템플릿 관련 플랜 항목 반영 (`plan.ft1`, `plan.ft2`)  
- i18n: `apps/web/src/i18n/messages.ts`  

### 1.7 기타 (이전 스레드에서 반영된 항목)

- API Docker: `docker-entrypoint.sh` CRLF/경로 이슈 완화 (`Dockerfile`, `.gitattributes`)  
- 규정 상세: 브레드크럼, 전문/분절 **세그먼트 토글** UI 개선

## 2. 변경 상세내용 (파일·API·동작)

### 2.1 데이터베이스 / Prisma

| 항목 | 내용 |
|------|------|
| 모델 | `PolicyTemplate` 추가, `Tenant`·`Policy` 관계 연결 |
| 컬럼 | `policies.template_id` → `policy_templates.id` (FK, `ON DELETE SET NULL`) |
| 마이그레이션 | `apps/api/prisma/migrations/20260417093000_policy_templates/migration.sql` |
| 스키마 | `apps/api/prisma/schema.prisma` |

### 2.2 백엔드 API (`apps/api`)

| 경로/모듈 | 변경 요약 |
|------------|------------|
| `src/templates/*` | 템플릿 모듈 전체 신규 |
| `templates.controller.ts` | `@MinPlan('pro')`, `@Roles('admin')` (쓰기), `GET :id/revisions` |
| `templates.service.ts` | CRUD/clone/setDefault, 플랜별 HTML·CSS 허용 검사, sanitize, **입력 검증(`validateTemplateShape`)**, 감사 `details`에 `before`/`after`/`snapshot` |
| `templates.dto.ts` | Create/Update/Clone DTO |
| `app.module.ts` | `TemplatesModule` import |
| `policies.service.ts` | `templateId` 검증, Starter 연결 거부, 목록/상세에 `template` include |
| `policies.dto.ts` | `CreatePolicyDto.templateId`, `UpdatePolicyDto.templateId` |
| `common/guards/plan.guard.ts` | 기존 `@MinPlan`과 연동 (변경 없이 사용) |

**템플릿 REST 요약**

- `GET /templates` — 목록 (Pro+)  
- `GET /templates/:id` — 단건  
- `GET /templates/:id/revisions` — 감사로그 기반 이력 (최대 50건, `template.*` 액션)  
- `POST|PUT|DELETE /templates...` — admin, Pro+  
- `POST /templates/:id/clone`, `POST .../set-default`  

**감사 액션 문자열**

- `template.create`, `template.update`, `template.delete`, `template.clone`, `template.setDefault`  
- 정책 템플릿 변경: `policy.update` (`fields`에 `templateId` 포함 가능)
