# v2 - Stability & Audit Hardening

작성일: 2026-04-17

## 목적
- v1 템플릿 플랫폼을 운영 가능한 수준으로 안정화
- 보안/검증/이력 복원 흐름 강화
- 사내 운영자가 변경 영향도를 빠르게 판단할 수 있는 도구 보강

## 핵심 개선 항목

### 1) 템플릿 입력 검증 강화 (Backend)
- 적용 파일: `apps/api/src/templates/templates.service.ts`
- 추가된 검증
  - 템플릿 이름 정규화(trim + 공백 축약)
  - 이름/설명 길이 제한
    - `name <= 120`, `description <= 500`
  - HTML/CSS 길이 제한
    - `rawHtml <= 200000`, `cssText <= 80000`
  - `layoutJson` 구조/모드 검증
    - `mode`는 `basic|html`
    - `basic` 모드는 `basicConfig` 필수
    - `html` 모드는 `rawHtml` 필수
    - `layoutJson` 전체 크기 제한
- 기대 효과
  - 비정상 payload/과대 payload로 인한 장애 가능성 감소
  - 템플릿 저장 형식 일관성 확보

### 2) HTML/CSS sanitize 강화 (Backend)
- 적용 파일: `apps/api/src/templates/templates.service.ts`
- 강화 내용
  - HTML:
    - 주석 제거
    - `<script>` 및 위험 태그(iframe/object/embed/form/input 등) 제거
    - 이벤트 핸들러 속성(`on*`) 제거
    - `javascript:`, `vbscript:`, `data:text/html` 제거
    - style 속성 내 `expression`, `@import`, 위험 `url(...)` 정리
  - CSS:
    - 주석 제거
    - `@import/@charset/@namespace` 차단
    - `expression`, `behavior`, `-moz-binding` 차단
    - 위험 `url(...)` 스킴 차단
- 기대 효과
  - 템플릿 기반 XSS/CSS 인젝션 위험 완화

### 3) 템플릿 이력 스냅샷 확장 (Backend)
- 적용 파일
  - `apps/api/src/templates/templates.service.ts`
  - `apps/api/src/templates/templates.controller.ts`
- 개선 내용
  - 템플릿 액션(create/update/clone/setDefault/delete)에 스냅샷 상세 기록
  - `GET /templates/:id/revisions` 제공

### 4) 템플릿 이력 운영 UX 고도화 (Frontend)
- 적용 파일
  - `apps/web/src/pages/SettingsPage.tsx`
  - `apps/web/src/api/templates.ts`
- 개선 내용
  - 이력 검색/필터
    - 액션 타입
    - 사용자/액션 검색
    - 기간(from/to)
    - 정렬(최신순/오래된순)
  - 이력 더보기(+10)로 리스트 확장
  - 영향도 배지
    - `critical/normal/minor`
  - 변경 카운트 배지
    - `N fields`, `layout N`, `css changed`
  - 상세 비교
    - Before/After JSON 라인 하이라이트
    - Semantic diff(키 단위 요약)
    - 변경 필드만 보기 토글
  - 복원 안전장치
    - 복원 전 확인 모달

### 5) 템플릿 Import/Export 안정화 (Frontend)
- 적용 파일: `apps/web/src/pages/SettingsPage.tsx`
- 개선 내용
  - Export 시 `schemaVersion`, `exportedAt` 포함
  - Import 시 schema/type 검증
  - 이름 충돌 시 자동 suffix 부여 (`(2)`, `(3)`, ...)

### 6) 실제 규정 기반 미리보기
- 적용 파일: `apps/web/src/pages/SettingsPage.tsx`
- 개선 내용
  - 미리보기 대상 규정 선택
  - 실제 정책 상세 데이터를 템플릿 미리보기에 반영

## 플랜 정책 현황 (v2 기준)
- Starter
  - 템플릿 기능 접근 불가 (업그레이드 유도)
- Pro
  - 템플릿 생성/적용/운영 가능
  - HTML/CSS 자유편집 불가 (기본 빌더 모드)
- Enterprise
  - HTML/CSS 자유편집 포함 전체 기능 가능

## 남은 고우선 과제
- sanitizer를 전용 검증 엔진(라이브러리) 기반으로 교체 검토
- 복원 API 전용 엔드포인트(명시적 restore action) 분리 검토
- 플랜/권한 조합 자동화 테스트(E2E) 추가
