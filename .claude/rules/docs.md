# 문서

- 산출물은 `docs/Deliverables/NN_분류/`의 최신본 하나를 고치고, 큰 개정은 과거본을 `구버전/`에 접미사(`_v1.0`)를 붙여 남긴다(개발컨벤션 6절).
- 작업관리대장의 ID(T·C·D)는 재사용하지 않는다. 새 할 일에는 출처 링크를 건다. 완료는 상태 칸을 `**완료(MM/DD)** → C-nn`으로 바꾸고 "완료" 표에 C 행을 더한다.
- 대장은 Edit 도구로 고친다. done-gate hook이 검토 없이 완료로 바꾸는 것을 막는데, 스크립트로 고치면 이 검사를 지나지 않는다.
- 대장·README·SRS는 다른 세션도 동시에 고친다 — 고치기 직전에 다시 읽고, 커밋은 /shared-commit 으로 내 줄만 올린다.
- 공개 저장소다: 운영 서버 주소·IP, 비밀값, 실제 계정 비밀번호를 적지 않는다.
- 한국어는 번역투 없이 자연스럽게 쓴다. 결정은 "누가, 언제, 무엇을" 남긴다.
